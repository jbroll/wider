# mapper

A chromeless desktop OpenStreetMap window. It runs as its own X11 window
with `WM_CLASS` `Mapper`, so wider can place it in a slot like any other
application.

## Install

```bash
npm install && npm run build
```

## Run

```bash
./mapper
```
